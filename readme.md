# Magia das Cores

Static website for the Magia das Cores multimedia showcase. The site is served directly from the repository root; `index.html` is the homepage.

## GitHub Pages

The `main` branch is deployed automatically by the workflow in `.github/workflows/deploy-pages.yml`. To enable it, open the repository's **Settings > Pages** and set the build and deployment source to **GitHub Actions**. The workflow can also be started manually from the **Actions** tab.

The pages and local asset filenames use lowercase paths so they work on GitHub's case-sensitive hosting.
